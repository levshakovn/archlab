## 📋 Quick Reference

### Getting Started
1. Read [README.md](./README.md) for setup instructions
2. Follow [DEPLOYMENT_SETUP.md](./DEPLOYMENT_SETUP.md) for deployment

### Before Launch
1. Run pre-deployment checks: `make check` (see [FINAL_CHECKS.md](./FINAL_CHECKS.md))
2. Complete [TESTING_GUIDE.md](./TESTING_GUIDE.md) testing checklist
3. Run tests: `make test` or `./scripts/run-tests.sh`

### Adding Features
- Adding puzzles: See [ADDING_PUZZLES.md](./ADDING_PUZZLES.md)
- Puzzle structure: See [PUZZLE_ERROR_STRUCTURE.md](./PUZZLE_ERROR_STRUCTURE.md)
