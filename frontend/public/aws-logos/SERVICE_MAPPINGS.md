# AWS Service Name to Logo File Mappings

This document shows how service names from puzzles map to logo filenames.

## Mapping Rules

1. Convert to lowercase
2. Replace spaces with hyphens
3. Replace `@` with hyphen
4. Replace `&` with `and`
5. Remove special characters
6. Add `.svg` extension
